Open-world crime game di kota pesisir Indonesia saat senja, dibangun ulang dengan model 3D asli (GLB): mobil rally, pohon, gedung, jalan dan NPC — plus peta lingkungan HDRI sunset, material PBR, tekstur foto, bloom dan tone mapping filmik. Raka pulang ke Teluk Senja: kejar gerbang balap di jalan pantai, lolos dari kejaran polisi, ngobrol sama warga, kumpulin hormat dan Koin Senja.
Jalankan `node serve.ts` lalu buka `http://127.0.0.1:8901/index.html`.
